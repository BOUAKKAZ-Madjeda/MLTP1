# Machine Learning Practical Session 1

Implementation of data exploration and preprocessing practical work covering tabular datasets, text data, missing value imputation, scaling, binarization, and categorical encoding.

## Structure
- `practical_session_1.ipynb`: complete notebook covering exercises 1 through 4
- `Iris_Dataset.csv`: iris tabular dataset
- `employees.csv`: employee demographic dataset
- `txt_file.txt`: raw text sample

## Requirements
- python 3.8+
- pandas
- numpy
- scikit-learn
- seaborn
- matplotlib

## Run
```bash
jupyter notebook practical_session_1.ipynb
```
